# User Stories

1. As a user, I want to view a list of all available gifts so that I can explore gift options.
2. As a user, I want to click on a gift so that I can view its detailed information.
3. As a user, I want to search for gifts by category or name so that I can find relevant items quickly.
4. As a new user, I want to register an account so that I can access personalized features.
5. As a registered user, I want to log in so that I can access my account.
6. As a user, I want to update my profile information so that my details remain accurate.
7. As a developer, I want to run code linting so that code quality and formatting are maintained.
8. As a developer, I want automated CI/CD pipelines so that new changes are tested and deployed safely.
